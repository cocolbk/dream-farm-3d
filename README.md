## Run (Windows)

Use `npm.cmd` (PowerShell script execution is blocked by default):

```bat
npm.cmd install
npm.cmd run dev
```

Open http://localhost:5173 → New Game → orbit with mouse / 1-finger drag, zoom with wheel / pinch, tap plots to farm.

```bat
npm.cmd run build      :: typecheck + production build into dist/
npm.cmd run typecheck
npm.cmd test           :: vitest: 44 tests (unit + integration)
npm.cmd run preview    :: serve dist/ locally to test the release build
```

## Install as app (PWA)

1. `npm.cmd run build`, then host `dist/` over HTTPS (or `npm.cmd run preview` for LAN test).
2. Open in Chrome/Edge on desktop or Android → main menu shows 📲 Install (or browser menu → Install).
3. Offline works after first visit (app shell cached; save data stays in localStorage and is never cached).

## Controls

- Camera: drag to orbit, wheel / pinch to zoom. Tap = action (not drag).
- Toolbar: 🌱 Plant (pick crop above) · 💧 Water · 🧺 Harvest · 🚜 Till (needs tractor) · ✨ Boost (fertilizer) · 🕹️ Drive (WASD/arrows or joystick) · 🏠 Build · ✋ Interact (plot info / building upgrades).
- Top bar: 🌱 Seeds · 🧺 Storage · 🏪 Shop · 🚗 Customers · 👥 Staff · 🗺️ Land · 🏆 Goals · 🚜 Tractors · 💰 Ledger.

## Game loop in 60 seconds

1. Plant maize on a tilled plot → water → harvest → move produce to 🏪 stock → set price.
2. Stall seeds with 🌱 Seeds; buy the T-20 tractor → till dark plots.
3. Stock the shop → customers arrive → hire 👥 staff to auto-serve → collect payday.
4. Unlock East/North fields, plant wheat/pumpkin, upgrade barn/shop/coop, chase 🏆 goals.

## Asset licensing

All 3D models are generated at runtime from Three.js primitives; icons are generated by `scripts/gen-icons.mjs`. No third-party art, textures, fonts or audio. Sound is synthesized with WebAudio.
